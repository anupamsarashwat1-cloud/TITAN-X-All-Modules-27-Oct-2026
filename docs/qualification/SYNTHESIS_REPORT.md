## 4. ASIC Physical Design (P&R) Readiness Assessment

> [!WARNING]
> **RTL verification candidate only; physical-design sign-off not established.**
>
> Generic cell counts reported in this document represent unmapped, technology-independent logic primitives generated by Yosys 0.33. The design is **NOT ready for physical design (Place & Route)** for the following reasons:
> 1. **No Target Standard Cell Mapping:** Synthesis was unmapped generic gates, not targeting an ASIC fab library (e.g., TSMC 28nm or SkyWater 130nm Liberty `.lib`).
> 2. **Behavioral Memory Arrays:** Register files and cache arrays are behavioral Verilog registers/arrays, not hardened SRAM macros.
> 3. **Missing Constraints:** No Synopsys Design Constraints (`.sdc`) for clocks, false paths, multi-cycle paths, or IO delays.
> 4. **No Clock Tree or Scan Chains:** Zero scan flip-flops (DFT) inserted; idealized single clock network.
> 5. **Top-Level Integration Gaps:** Core interconnect, isolated L2 cache, omitted peripherals, and snoop tie-offs must be resolved before full-chip physical implementation.
