# Storage

## Description
The storage subsystem manages non-volatile data storage.

## Working
Includes controllers for USB OTG, MMC/SD, and QSPI flash.

## Need
Required for persistent storage of firmware, operating systems, and user data.

## Steps to Use / Integrate
1. Instantiate storage controllers.
2. Connect to interconnect and physical pins.
3. Verify data read/write operations.
